## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## 运营纲领（开工必读）

**开工前先读 `DOCTRINE.md`。** 它规定了本站的运营原则、禁止事项和止损线。

三条最要紧的：
1. **第 0 步是插电，不是产内容**——88 条联盟链接是自造参数、GA4 没装，
   所以「收入 $0」信息量为零。在装上一个真联盟 ID 并验证点击能被记录之前，
   任何内容/SEO 工作都在乘以零。
2. **每个数字必须有可点开的第三方溯源 URL，做不到就不上站**——
   这是对 500 处编造事故的机制性修复。信任信号是无法被生成的字段，
   靠自律防不住，必须结构上让「没有来源」无法通过。
3. **禁止刷新 pubDate、禁止铺 FAQPage schema、禁止把页面数/展现量当进度**——
   详见 DOCTRINE.md 的假进度清单。
